# Koperasi BATARU Store

Aplikasi toko online modern untuk Koperasi BATARU.

## Cara menjalankan

1. `npm install`
2. `npm run dev`
3. Buka `http://localhost:4173`

## Fitur

- Halaman beranda dengan hero dan promo koperasi
- Katalog produk
- Keranjang belanja interaktif
- UI responsif dan modern dengan Tailwind CSS
